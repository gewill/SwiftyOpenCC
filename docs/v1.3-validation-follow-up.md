## Completed in this change

- **R4, controlled resource generation:** the generator uses the official CMake 4.4.3 macOS universal archive and its checked-in SHA-256. Download and cached-archive hash failures stop before extraction/execution. A wrong reported tool version is rejected. Downloads and tools stay in `.build`; there is no global tool installation.
- The resource manifest records that tool source/version/hash, all explicit configure/build arguments, configured C++ compiler identity/version and generation host. Compiler/OS versions are recorded rather than pinned; bit-for-bit results across different toolchains are not claimed.
- Removed the entire resource build directory and generated twice on the same host. The complete manifests matched byte-for-byte. All 42 resource checksums match the pre-change manifest; no dictionaries, compatibility configurations, public options or native implementation changed.
- **R5, official CLI comparison:** independently built the same core's CLI and dictionaries, then compared 495 same-release fixture conversions plus 70 Unicode/newline/empty/phrase-boundary cases across ten modes. All **565 byte comparisons passed**. A separate fixed NUL assertion passed; existing four compatibility-mode expectations remain in Swift tests.
- The official fixture JSON contains trailing commas. It is decoded by Foundation, as in the existing Swift tests, without modifying the upstream file or regex-normalizing text.
- The CLI defaults to excluding dictionaries marked as potentially producing missing-glyph characters; the library's `ConfigLoadOptions` defaults to including them. The parity command explicitly uses `--include-tofu-risk-dictionaries` to match existing wrapper behavior. An initial run without this option correctly exposed a difference for `殢` in `t2s`; no wrapper semantics or fixture expectations were rewritten.
- An independent negative control temporarily mapped `s2t` to simplified flags in the Python process. The real wrapper/CLI comparison rejected it at `case_014:s2t`; production files stayed unchanged. Failed runs replace any prior green JSON report with a failure record.

The [recorded CLI summary](official-cli-1.4.2-validation.json) includes compiler, source/configuration hashes, coverage and an inventory digest. Full per-case JSON is produced at `.build/official-cli-report.json` and retained by CI for 14 days. [The maintenance guide](upstream-sync.md) lists reproduction commands.
